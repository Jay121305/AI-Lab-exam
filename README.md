# AI Lab Assignment C++ Solutions

This folder contains one separate interactive C++ program for each question in
the AI lab assignment list.

Run with a C++17 compiler, for example:

```powershell
g++ -std=c++17 q02_bfs_water_jug.cpp -o q02
.\q02.exe
```

Each program:

- asks the user for input,
- provides useful default values in square brackets,
- keeps the code short but complete,
- includes comments explaining what the code does and why the algorithm is used.

Note: Q15 and Q16 keep the assignment's depth limit of 3 by default. For the
classic Missionaries/Cannibals and full 8-Queens problems, depth 3 is not deep
enough for a complete solution, so those programs correctly report that.
